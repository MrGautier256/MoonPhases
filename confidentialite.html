Politique de confidentialité

Dernière mise à jour : 13 novembre 2026

Cette politique couvre le site Phase Lunaire (https://kronys256.github.io/MoonPhases/) et l’application Android « Phase Lunaire », qui affiche ce même site.

Éditeur et contact

Kronys. Pour toute question : mrgautier256.contact@gmail.com.

En bref

  • Aucun compte, aucune publicité, aucune mesure d’audience, aucun cookie.
  • Aucun serveur appartenant à l’éditeur : l’éditeur ne reçoit aucune donnée.
  • Les phases de la Lune, les levers, les couchers et le fuseau horaire sont calculés sur votre appareil, avec les bibliothèques SunCalc et tz-lookup incluses dans le site.

Votre position

La position est facultative. Elle n’est demandée que si vous touchez « Ma position », et sert aux calculs faits sur votre appareil. Pour afficher le nom du lieu, des coordonnées arrondies à deux décimales (environ 1 km) sont envoyées au service Photon, exploité par komoot. C’est aussi le cas quand vous touchez un point de la carte.

Recherche de lieu

Le texte que vous saisissez dans la recherche est envoyé à Photon (komoot) pendant la frappe, à partir de trois caractères, pour proposer des lieux.

Carte

Quand vous ouvrez la carte, ses images sont téléchargées depuis les serveurs d’OpenStreetMap (Fondation OpenStreetMap), qui reçoivent votre adresse IP et la zone affichée.

Hébergement

Le site est hébergé par GitHub Pages. GitHub peut conserver des journaux techniques, dont votre adresse IP.

Données conservées sur votre appareil

Le site enregistre quelques réglages dans le stockage local de votre navigateur. Ils ne sont jamais envoyés :

  • moonphases.place : le dernier lieu choisi (nom et coordonnées) ;
  • moonphases.recent : les derniers lieux choisis, 4 au maximum ;
  • moonphases.moonStyle : le style de Lune choisi, dessinée ou réaliste.

Pour les effacer : « Oublier ce lieu » dans le choix du lieu retire le lieu actuel, et vider les données du site dans les réglages de votre navigateur efface tout. Dans l’application Android, ces données sont gérées par Chrome pour ce site : Chrome, Paramètres, Paramètres des sites, puis kronys256.github.io.

Vos droits

L’éditeur ne détenant aucune donnée vous concernant, les demandes portant sur les données reçues par komoot, la Fondation OpenStreetMap ou GitHub se font directement auprès d’eux. Pour toute question, vous pouvez écrire à l’adresse ci-dessus. Vous pouvez aussi adresser une réclamation à la CNIL.
